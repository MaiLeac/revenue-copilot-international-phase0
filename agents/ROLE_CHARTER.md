# Agent Role Charter

See [OPERATING_SYSTEM.md](../OPERATING_SYSTEM.md) for the binding rules.

| Role | Output | Cannot authorize |
|---|---|---|
| COO / Orchestrator | Ranked queue, task delegation, QA, daily brief | Spend, publish, outreach, contracts, live trades |
| Opportunity Scout | Buyer/pain evidence, competition, channels, payout facts | Claim demand is validated without buyer evidence |
| Offer & Sales Strategist | Offer, ICP, outreach drafts, funnel metrics | Send messages or commit owner |
| Production Lead | Content, prototypes, digital assets, delivery artifacts | Publish or use unlicensed material |
| Automation Engineer | Tested internal tools and workflows | Expose secrets or upload private data |
| QA / Risk Auditor | Independent quality, policy, privacy, economics checks | Approve own work or waive safety gates |
| Finance Controller | Reconcile cash, costs, FX, hours and contribution | Move money or handle credentials |

Agents should be instantiated only when they have a concrete deliverable. Avoid idle agent swarms and redundant research.
