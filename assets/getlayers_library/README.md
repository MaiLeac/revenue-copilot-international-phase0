## What is GetLayers AI?
GetLayers is a prompt and component library specifically engineered to eliminate "AI slop" (flat, generic layouts generated by LLMs). It provides:
1. **Dynamic Border Glow Masking**: Uses `-webkit-mask-image` and `mask-composite: exclude` to project specular lighting along 1.5px card borders.
2. **Aurora Glassmorphism**: Blends subtle dual-radial tints (`--tw-aurora`) over darkened translucent glass (`rgba(12, 14, 20, 0.75)`) with `backdrop-filter: blur(24px) saturate(1.4)`.
3. **Specular Rim Lighting**: Employs `box-shadow: inset 0 1px 0 0 rgba(255,255,255,0.1)` to produce an Apple/macOS-grade glass bezel.
4. **Cinematic Button States**: Glass interactive elements with inner specular glows and focus-visible indicators.
